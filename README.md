# Visit Cambodia - Kingdom of Wonder 2026

A premium, minimalist tourism platform dedicated to showcasing the sacred and serene landscapes of Cambodia.

## Project Structure
- **8 HTML Pages**: Curated experiences from Heritage guides to interactive Journey Architects.
- **Tailwind CSS**: Custom utility-first styling for a premium feel.
- **Responsive Design**: Optimized for all devices with a focus on immersive visuals.


## Technologies
- HTML5 / CSS3 / JavaScript
- Tailwind CSS (v3+)
- Premium Google Fonts (Playfair Display & Inter)

## Recent Updates

- Interactive Destination filtering system.
- Polished accessibility and interactive feedback across all touchpoints.
